# 用工管家 AI Agent（网页版）

> 面向中小企业与律所的**企业用工合规管理系统**：录入用工数据 → 116 条劳动法规则自动扫描 → 风险下钻到具体的人 → 派发整改闭环 → AI 用人话解读并给出可执行整改步骤。

- **在线体验**：https://yongong-guanjia-production.up.railway.app
- **代码仓库**：https://github.com/nxwangjun/yongong-guanjia-web
- 许可：MIT　|　AI 能力：真实大模型（RAG 检索增强，模型 `deepseek-v3`）

## 一、解决什么问题

中小企业普遍没有专职法务，用工违规（未签合同、试用期超限、加班超时、低于最低工资、未缴社保、证照过期）往往在劳动监察或仲裁发生时才被发现，此时已是罚款与赔偿。

本系统把这套排查做成随时可用的工具：

| 环节 | 以前 | 现在 |
|---|---|---|
| 发现问题 | 等员工投诉或监察上门 | 录入数据后一键扫描，主动暴露 |
| 定位问题 | 只知道"好像有问题" | 下钻到"王五入职 448 天无合同" |
| 整改 | 不知道改什么 | 每条风险附法条 + 后果 + 分步骤整改 |
| 请教律师 | 小事也要付费咨询 | 先问 AI（附法条依据），必要时再找律师 |

## 二、快速开始

**零第三方依赖，无需 npm install。**

```bash
node server.js          # 启动（默认 http://localhost:3000）
```

打开浏览器访问 `http://localhost:3000` 即可。首次启动自动生成 12 人演示数据（预埋 9 类常见风险，可直接看到扫描效果）。

其他命令：

```bash
npm test                # 端到端冒烟测试（16 项）
npm run corpus          # 重建劳动法检索语料（需本地既有知识库）
npm run rules           # 重建 116 条规则库（需本地既有知识库）
```

> 要求 Node ≥ 18（用到内置 `fetch`）。知识语料已随仓库提交，clone 下来即可运行。

| 角色 | 账号 | 密码 | 能看的模块 | 数据范围 |
|---|---|---|---|---|
| 管理员 | `admin` | `admin123` | 全部 20 个模块 | 全部 |
| 人力资源 | `hr` | `hr123` | 管人 6 个 + 风险清单/处置/问卷 | 全部 |

## 四、技术实现

### 整体架构

```
浏览器（原生 JS SPA）
      │
      ▼
Node 内置 http 服务（server.js，零第三方依赖）
      ├── 业务 API（CRUD / 扫描 / 处置 / 导入导出 / 审计）
      ├── 扫描引擎（engine.js：116 条规则判定）
      ├── 检索器（retriever.js：BM25，469 条劳动法语料）
      └── AI 智能体（agent.js）
              ├── 真实大模型调用（OpenAI 兼容协议）
              └── 未配置密钥时 → 本地规则引擎兜底（明确标注，不伪装 AI）
```

### 关键技术点

**1. 检索增强（RAG）**
自建 BM25 检索器，中文按「单字 + 二元组」切分（无需分词库），在 469 条语料（249 条法条正文 + 116 条规则 + 104 条风险点）上召回依据，作为大模型作答的**唯一事实来源**。所有 AI 回答必须基于检索到的法条，超出知识库时明确说明"未覆盖，建议咨询律师"，从机制上抑制幻觉。

**2. 真实大模型接入**
标准 OpenAI 兼容协议 `/chat/completions`，默认 DeepSeek，可换任意兼容端点（OpenAI / 通义 / 智谱 / 比赛方接口等）。密钥走 `.env`，也支持在页面「系统设置」里粘贴、立即生效。

**3. 双引擎降级（不伪造 AI）**
未配置密钥或调用失败时，自动切换本地规则引擎——仍基于同一份语料检索并结构化合成，但**在返回结果中标注 `mode:'local'` 并明确提示"非 AI"**。绝不把规则输出伪装成 AI 生成。

**4. 规则判定（原创实现）**
10 条 `auto` 规则由系统数据直接算出（可下钻到人），105 条 `ask` 走确认台账或问卷，1 条 `hybrid` 两者结合。判定逻辑（试用期上限、加班上限、最低工资、试用期工资 80% 等）在本项目中重新实现。

**5. 法条来源**
法条正文取自元典核验的现行有效版本，逐条记录发布/实施日期与文号；风险规则与自检点沿用已核验的法律知识点。

## 五、AI 配置

复制 `.env.example` 为 `.env`，填入：

```ini
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-你的密钥
LLM_MODEL=deepseek-chat
```

或在页面「系统设置 → 大模型配置」里直接粘贴，立即生效（会写入 `.env`）。

未配置时系统仍可完整运行（本地规则引擎兜底），但 AI 相关能力不可用。

```
├── server.js              服务端入口（零依赖 http）
├── src/
│   ├── config.js          配置（自带 .env 解析）

│   ├── corpus.js          语料与问卷加载
│   ├── prompt.js          提示词模板
│   └── agent.js           大模型调用 / 解读 / 问答 / 降级
├── public/                前端（原生 SPA，无构建）
│   ├── index.html
│   ├── style.css
│   └── js/  api.js · ui.js · app.js · pages/{hr,risk,flow,system}.js
├── data/                  知识数据（corpus / quiz / rules 随仓库提交）
├── scripts/               语料与规则构建脚本
├── tests/smoke.js         端到端冒烟测试（16 项）
└── docs/                  设计与路演文档
```

## 七、部署

标准 Node 服务，可部署到任意 Node 主机（Railway、Render、Fly.io、云服务器等）：

```bash
node server.js     # 监听 process.env.PORT || 3000
```

也可直接用内置 Dockerfile 方式打包（见 `docs/`）。
