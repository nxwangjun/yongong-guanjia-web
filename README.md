# 小哲用工风险检测系统（网页版 · 免登录）

> 面向中小企业的**用工风险检测工具**：录入或导入用工数据（员工、合同、考勤、薪资、社保、证照）→ 系统自动测算每个人身上的用工风险 → 算不出的走合规自查 → 每条风险附法条与整改步骤 → AI 用人话解读。

- **在线体验**：https://yongong-guanjia-production.up.railway.app
- **代码仓库**：https://github.com/nxwangjun/yongong-guanjia-web
- 许可：MIT　|　AI 能力：真实大模型（RAG 检索增强）

## 一、解决什么问题

中小企业普遍没有专职法务，用工违规（未签合同、试用期超限、加班超时、低于最低工资、未缴社保、证照过期）往往在劳动监察或仲裁发生时才被发现，此时已是罚款与赔偿。

本系统把这套排查做成随时可用的工具：

| 环节 | 以前 | 现在 |
|---|---|---|
| 发现问题 | 等员工投诉或监察上门 | 录入数据后自动测算，主动暴露 |
| 定位问题 | 只知道"好像有问题" | 下钻到"张三入职 448 天无合同" |
| 整改 | 不知道改什么 | 每条风险附法条 + 后果 + 分步骤整改 |
| 请教律师 | 小事也要付费咨询 | 先问 AI（附法条依据），必要时再找律师 |

**免登录、开箱即用**：打开网页即用，业务数据只存在访问者自己的浏览器（localStorage），不上传服务器——评委打开链接看到的是同一套 36 人演示数据，自己录入的数据只影响自己这台机器。

## 二、快速开始

**零第三方依赖，无需 npm install。**

```bash
node server.js          # 启动（默认 http://localhost:3000）
```

打开浏览器访问 `http://localhost:3000` 即可。首次打开自动载入 36 人演示数据（预埋 18 类常见风险，可直接看到检测效果）；首页可一键「清空从白板开始」或「恢复演示数据」。

其他命令：

```bash
node tests/smoke.js          # 端到端冒烟测试（33 项断言，需先启动 server.js）
node scripts/build-browser.js  # 改了 src/engine.js / src/db.js / data/*.json 后重建前端 bundle
```

> 要求 Node ≥ 18（用到内置 `fetch`）。规则库、问卷、劳动法检索语料均已随仓库提交，clone 下来即可运行。

## 三、功能清单

### 结论（核心价值）
| 模块 | 说明 |
|---|---|
| **风险概览** | 检测覆盖情况 + 风险概要（扫出的问题自动总结：高危几条、集中在哪几类、涉及多少人、建议先处理什么） |
| **员工风险画像** | 逐人列出命中了哪些风险、为什么、依据哪条法、怎么整改 |
| **用工风险清单** | 一键扫描；按严重程度排序；**下钻到具体哪个人、为什么**；附法条原文；AI 逐条解读 |

### 数据填入
| 模块 | 说明 |
|---|---|
| 员工档案 | 花名册、在职状态、入离职、工号 |
| 合同信息 | 签订、续签、到期；试用期上限按合同期限自动核算 |
| 考勤工时 | 出勤与加班记录，月加班超 36 小时触发风险 |
| 薪资 | 月工资、加班费；低于最低工资 / 试用期工资不足转正 80% 触发风险 |
| 社保 | 参保状态与基数，在职无参保、基数低于工资触发风险 |
| 证件资质 | 特种作业证等有效期管理，到期前提醒 |
| 数据导入导出 | JSON 整包导入导出 + CSV 单表导入导出（下载模板 / 预览确认 / 导入后引导扫描） |

### 风险确认
| 模块 | 说明 |
|---|---|
| **合规自查** | 系统算不出的 106 条，勾选后点「提交自查结果」统一入库，没做到的直接进用工风险清单 |
| **判定阈值** | 所在地区（自动带出当地最低工资，31 省档位内嵌）、最低工资档位、签约期限、加班上限、合同/证照到期提醒天数 |
| **AI 问答** | 自由提问劳动法问题，基于知识库检索作答并附依据 |

### 系统
| 模块 | 说明 |
|---|---|
| **规则配置** | 全部 124 条规则统一启停（含扩充自动规则与证照临期提醒），停用后该条不参与扫描 |
| 系统设置 | **大模型密钥配置**（OpenAI 兼容端点，粘贴即生效，写入 .env 持久化） |

## 四、技术实现

### 整体架构（免登录 A1）

```
浏览器（原生 JS SPA）
      ├── 业务数据：localStorage 单键 yg_db（员工/合同/考勤/薪资/社保/证照/台账…）
      ├── 扫描引擎：engine-browser.js 浏览器直跑（124 条规则判定）
      └── AI 调用 ──► Node 内置 http 服务（server.js，零第三方依赖）
                        ├── 静态资源 + /api/health
                        ├── /api/ai/*（diagnose / explain / chat）
                        │     ├── 检索器（retriever.js：BM25，469 条劳动法语料）
                        │     └── AI 智能体（agent.js）
                        │           ├── 真实大模型调用（OpenAI 兼容协议）
                        │           └── 未配置密钥时 → 本地规则引擎兜底（明确标注，不伪装 AI）
                        └── /api/config-key（保存页面粘贴的密钥）
```

服务器不保存任何业务数据；旧的服务端业务接口已统一下线（返回 410）。

### 关键技术点

**1. 检索增强（RAG）**
自建 BM25 检索器，中文按「单字 + 二元组」切分（无需分词库），在 469 条语料（249 条法条正文 + 116 条规则 + 104 条风险点）上召回依据，作为大模型作答的**唯一事实来源**。所有 AI 回答必须基于检索到的法条，超出知识库时明确说明"未覆盖，建议咨询律师"，从机制上抑制幻觉。

**2. 真实大模型接入**
标准 OpenAI 兼容协议 `/chat/completions`，可接任意兼容端点（DeepSeek / OpenAI / 通义 / 智谱 / 比赛方接口等）。密钥走 `.env`，也支持在页面「系统设置」里粘贴、立即生效（写入 `.env` 持久化）。

**3. 双引擎降级（不伪造 AI）**
未配置密钥或调用失败时，自动切换本地规则引擎——仍基于同一份语料检索并结构化合成，但**在返回结果中标注 `mode:'local'` 并明确提示"非 AI"**。绝不把规则输出伪装成 AI 生成。

**4. 规则判定（原创实现，共 124 条）**
- **18 条由数据自动测算、下钻到人**：规则库 auto 10 条（未签合同、满一年未签视为无固定期限、试用期超限、二次固定期限、月加班超 36 小时、低于最低工资、试用期工资不足 80%、未缴社保、离职无证明等）+ 扩充自动规则 7 条（合同到期未续签、社保基数低于工资、试用期工资低于最低工资、加班费低于法定标准、加班费占比异常等）+ 证照临期提醒 1 条；
- **106 条走合规自查**：系统算不出的管理动作（规章制度、民主程序、专项协议等），逐条台账确认或问卷作答。
判定逻辑在本项目中重新实现；所有规则的启停在「规则配置」页统一控制，停用后立即不参与扫描。

**5. 法条来源**
法条正文取自元典核验的现行有效版本，逐条记录发布/实施日期与文号。

## 五、AI 配置

复制 `.env.example` 为 `.env`，填入：

```ini
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-你的密钥
LLM_MODEL=deepseek-chat
```

或在页面「系统设置」里直接粘贴，立即生效（会写入 `.env`）。

未配置时系统仍可完整运行（本地规则引擎兜底），AI 回答会明确标注"本地规则引擎，非 AI"。

## 六、目录结构

```
├── server.js              服务端入口（零依赖 http：静态 + AI 代理 + health）
├── src/
│   ├── config.js          配置（自带 .env 解析）
│   ├── engine.js          124 条规则扫描引擎（含扩充自动规则）
│   ├── region.js          31 省最低工资档位
│   ├── retriever.js       BM25 检索器
│   ├── corpus.js          语料与问卷加载
│   ├── prompt.js          提示词模板
│   ├── agent.js           大模型调用 / 解读 / 问答 / 降级
│   └── db.js              演示种子数据源（仅供 build-browser.js 提取，勿删）
├── public/                前端（原生 SPA，无构建步骤）
│   ├── index.html
│   ├── style.css
│   └── js/  api.js · ui.js · app.js · csv.js · pages/{hr,risk,system,people}.js
│       （data-bundle.js / seed.js / engine-browser.js 由 scripts/build-browser.js 生成）
├── data/                  知识数据（corpus / quiz / rules / region 随仓库提交）
├── scripts/               语料、规则、前端 bundle 构建脚本
├── tests/                 冒烟测试（smoke.js，33 项断言）
└── docs/                  设计与路演文档
```

## 七、部署

标准 Node 服务，可部署到任意 Node 主机（Railway、Render、Fly.io、云服务器等）：

```bash
node server.js     # 监听 process.env.PORT || 3000
```

仓库根目录附 Dockerfile。业务数据在访问者浏览器本地，服务器只托管静态页与 AI 代理，天然支持多人同时访问互不影响。
