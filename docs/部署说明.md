# 部署说明

## 本地运行（最简单）

```bash
node server.js      # 打开 http://localhost:3000
```

零第三方依赖，不需要 `npm install`。需要 Node ≥ 18。

## 环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `PORT` | 否 | 默认 3000 |
| `LLM_BASE_URL` | 否 | 默认 `https://api.deepseek.com/v1` |
| `LLM_API_KEY` | 否 | 不填则自动降级为本地规则引擎（仍可完整演示） |
| `LLM_MODEL` | 否 | 默认 `deepseek-chat` |
| `TOP_K` | 否 | 检索召回条数，默认 6 |

## 云平台部署

### Railway / Render / Fly.io（推荐）

1. 把仓库推到 GitHub
2. 在平台选择 "Deploy from repo"
3. Build Command 留空（无需构建），Start Command 填 `node server.js`
4. 环境变量里填 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`
5. 部署完成后会分配一个公网域名

### Docker

```bash
docker build -t yongong-guanjia .
docker run -p 3000:3000 \
  -e LLM_API_KEY=sk-你的密钥 \
  -e LLM_BASE_URL=https://api.openai-next.com/v1 \
  -e LLM_MODEL=deepseek-v3 \
  yongong-guanjia
```

## 部署后自检

访问 `https://你的域名/api/health`，返回中包含：

```json
{ "ok": true, "llmEnabled": true, "corpusSize": 469, "quizCategories": 20 }
```

`llmEnabled: true` 表示真实大模型已接入。

## 注意事项

- 数据存在服务端 `data/db.json`，单实例部署即可；多实例需改为外部数据库。
- `.env` 已在 `.gitignore` 中，不要把密钥提交到仓库。
